# Conciliador IATA–Maveric Paraguay

Canal de actualización de Sevens para Mac y Windows. El acceso de Escritorio consulta el último release estable y descarga `latest_mac.zip` o `latest_pc.zip`.

Las actualizaciones contienen solamente el programa, sin UUID de equipos, credenciales, conciliaciones ni archivos de clientes. Los instaladores iniciales con activaciones se entregan por separado desde el repositorio privado.

Si Paraguay ya está abierto, cerrarlo desde su botón y abrirlo de nuevo desde Escritorio para recibir una versión nueva. Sin conexión, continúa funcionando la versión instalada.

Primera versión de distribución: v1.0.1 · 20/10/2026.
